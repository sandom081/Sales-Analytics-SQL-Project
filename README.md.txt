# Sales Analytics SQL Project

## Project Overview

This project analyzes sales data using MySQL.

The project covers customer analysis, product analysis, order analysis, and revenue analysis using SQL queries.

---

## Dataset

The project contains three tables:

- Customers
- Orders
- Products

---

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()
- INNER JOIN
- LEFT JOIN

---

## Business Problems Solved

- Total Customers
- Total Products
- Total Orders
- Most Expensive Product
- Revenue Analysis
- Top Customers
- Top Selling Products
- Revenue by Category
- Customers with No Orders
- Products Never Ordered

---

## Tools Used

- MySQL Workbench
- MySQL Server
